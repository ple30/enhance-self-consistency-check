## Codebase for the paper "Enhancing Assessment of Self-Consistency in LLM Explanations using Perturbation Strength"

Phuong Quynh Le, Kemal Kurniawan, and Jey Han Lau. 2026. Enhancing Assessment of Self-Consistency in LLM
Explanations using Perturbation Strength. [Preprint](https://doi.org/10.48550/arXiv.2609.30849), arXiv:2609.30849. Accepted for publication at ALTA 2026.

**Note**: This repository is a work in progress. Some code is not yet available and the repository structure is still being organised. Further updates will be made to improve code quality and completeness. Please refer to the paper cited above for the complete report. 

### Evaluation of perturbation strength measures on human-annotated data
- The human-annotated data can be found in [annotation_data](annotation_data/). See [annotation_data/README.md](annotation_data/README.md) for its source and column descriptions.
- Perturbation Strength Rating Guide for Human annotators: [Perturbation Strength Rating Guide.docx](Perturbation%20Strength%20Rating%20Guide.docx).
